# EYAN Automation Hub

> A standalone, self-hosted workflow automation platform built to demonstrate professional automation engineering, AI integrations, and production-ready infrastructure using n8n.

---

# Executive Summary

EYAN Automation Hub is a portfolio project focused on workflow automation engineering.

The project demonstrates how to design, deploy, document, monitor, and maintain business automation solutions using a self-hosted n8n environment.

Unlike EYAN Studio, which showcases full-stack software engineering and AI application development, Automation Hub focuses on automation architecture, workflow design, API integrations, AI-powered automations, operational excellence, and infrastructure best practices.

This repository is intentionally maintained as an independent project with its own lifecycle, deployment, documentation, and versioning.
